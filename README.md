# GWA Calculator

A simple and minimalist GWA Calculator built for students to easily calculate their General Weighted Average.

## Features

- Add multiple subjects
- Enter subject units
- Enter grades
- Calculate weighted GWA
- Light and dark mode
- Responsive design
- Simple and clean interface

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite
